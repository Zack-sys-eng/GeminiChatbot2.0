# ✨ Get Chat – AI Assistant

**Get Chat** is a modern, responsive AI chatbot application powered by the **Google Gemini API**. It provides an interactive chat interface where users can ask questions, learn new topics, generate ideas, write code, and receive AI-powered responses.

The application features a clean dark-themed interface with smooth animations, real-time AI communication, and a simple API key configuration system.

---

## 🚀 Features

* 🤖 **Google Gemini AI Integration** – Generate intelligent AI-powered responses.
* 💬 **Interactive Chat Interface** – Communicate with the AI assistant in real time.
* 🎨 **Modern Dark UI** – Attractive interface with gradient effects and a clean design.
* 📱 **Responsive Design** – Supports desktop, tablet, and mobile screens.
* ✨ **Typing Indicator** – Animated typing effect while the AI generates responses.
* 🔑 **API Key Configuration** – Connect your own Gemini API key through the settings panel.
* 💡 **Quick Suggestions** – Predefined prompts for learning, coding, creativity, and advice.
* 🔄 **New Chat Functionality** – Start a fresh conversation whenever needed.
* ⚡ **Automatic Retry System** – Automatically retries requests when temporary network or API errors occur.
* ⌨️ **Keyboard Shortcuts** – Press Enter to send messages and Shift + Enter for a new line.
* 📜 **Conversation Context** – Maintains conversation context during the current chat session.

---

## 🔑 Google Gemini API Setup

Follow these steps to connect your AI assistant to Google Gemini.

**Step 1:** Visit Google AI Studio.

**Step 2:** Sign in using your Google account.

**Step 3:** Generate your Gemini API key.

**Step 4:** Open the Get Chat application in your browser.

**Step 5:** The API Settings window will appear automatically.

**Step 6:** Paste your Gemini API key into the input field.

**Step 7:** Click the Save Key button.

Your application is now ready to communicate with Google Gemini AI.

---

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Right-click and select **Open with Live Server**, or open the HTML file directly in your browser.
5. Configure your Gemini API key through API Settings.
6. Start chatting with your AI assistant.

## 💻 Application Functionalities

### 1. AI Chat System

Users can enter questions and receive responses generated by Google Gemini AI.

### 2. Quick Prompt Suggestions

The application provides four predefined categories:

* Learn Something
* Generate Ideas
* Write Code
* Get Advice

### 3. API Settings

Users can enter and save their Gemini API key using the settings interface.

### 4. New Chat

The New Chat button clears the current conversation and allows users to start again.

### 5. Error Handling

The application includes error handling and automatic retry functionality for temporary network and API failures.

## 🔐 Security Note

* Never upload your personal Gemini API key to GitHub.
* The API key is stored temporarily using browser session storage.
* This project is designed as a frontend demonstration. For production deployment, API requests should be handled through a secure backend server to protect API credentials.
